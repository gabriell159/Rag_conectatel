# 2. README de execução

O README de execução da solução deve ficar na RAIZ do repositório de
código da squad (não nesta pasta), para que qualquer pessoa consiga rodar
o projeto sem ajuda. Use o README.md deste scaffold como ponto de partida
e adapte para os passos reais da solução da squad.

Antes de 02/09, um membro da squad que não tenha escrito a configuração
original deve executar o README do zero e a squad deve corrigir o que
travar nesse teste.
